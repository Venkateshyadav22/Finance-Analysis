# 💰 Finance Analysis Dashboard | Power BI

## 📝 Short Description / Purpose
An interactive Power BI dashboard designed to monitor and analyze financial transactions, customer behavior, fees, taxes, and performance across different business segments and regions.  
This project provides stakeholders with real-time insights into KPIs, transaction trends, and customer demographics to improve financial decision-making and strategy.

## ⚙️ Tech Stack
- 📊 Power BI Desktop – Main data visualization platform  
- 📂 Power Query – Data transformation and cleaning  
- 🧠 DAX (Data Analysis Expressions) – Calculated measures and dynamic visuals  
- 📝 Data Modeling – Relationships among tables for cross-filtering and aggregation  
- 📁 File Format – `.pbix` for development and `.png` for dashboard preview  

## 📂 Data Source
Source: Kaggle – Finance Transactions Dataset.  


## 🌟 Business Problem
Financial organizations face challenges in tracking overall transaction growth, customer segment contribution, and state-wise performance.  
Key questions include:  
- How are transactions performing year-over-year?  
- Which customer segments and states contribute most to revenue?  
- What is the success vs failure rate of transactions?  
- Which transaction types are most profitable?  
- How do gender demographics influence transaction amounts?  

## 🎯 KPI Requirements
- Total Amount - Overall transaction value with YoY comparison  
- Total Transactions - Number of transactions processed annually  
- Average Transaction Value - Mean transaction size  
- Total Fees - Fees collected from transactions  
- Total Tax - Tax generated from transactions  

## 📊 Charts Requirement
- Total Amount by Month (Line/Area Chart) - Monthly transaction trends and seasonal spikes  
- Total Amount by Transaction Status (Donut Chart) - Success vs Failed vs Pending transactions  
- Total Amount by Customer Segment (Bar Chart) - Retail, Premium, SME, Corporate, Wealth contributions  
- Total Amount by State (Bar Chart) - Regional performance comparison  
- Transaction Type Analysis (Matrix/Heatmap) - Amount, Fees, Tax, Transaction count by type (Bill Payment, Card Payment, Deposit, Refund, Transfer, Withdrawal, etc.)  
- Total Amount by Gender (Donut Chart) - Male vs Female contribution

## 💡 Business Impact & Insights
- Enables management to track financial KPIs in real time  
- Identifies high-performing customer segments and states  
- Provides clarity on transaction success rates and operational efficiency  
- Supports profitability analysis by transaction type  
- Enhances strategic decision-making with demographic insights
